# 枪管 CAN 通信协议

版本：v3.5　　适用工程：`SHOOT_cmzy_REV081`

本文档与当前固件实现对应，是 CAN 报文的最终定义。协议为经典 CAN、标准 11 位 ID、数据帧（`CAN_RTR_DATA`），波特率 500 kbps。多字节整数均为小端序。CAN ID 越小，仲裁优先级越高。

## 1. ID 分层与分配

| 层 | ID 范围 | 说明 |
|---|---|---|
| 调试层 | `0x20x` | 预留调试报文 |
| 故障层 | `0x21x` | 强故障、弱故障、启动状态 |
| 设备层 | `0x22x` | 传感器校正 |
| 应用层 | `0x23x` | 射击状态、LED/队伍/热量控制 |

| ID | 方向 | 报文 | DLC | 行为 |
|---:|---|---|---:|---|
| `0x200` | 枪管→上位机 | 调试心跳（预留） | 8 | 当前固件不发送 |
| `0x210` | 枪管→上位机 | 强故障复位后上报 | 1 | 复位后初始化完成时发送 |
| `0x211` | 枪管→上位机 | 弱故障状态 | 1 | 故障发生、持续或清除时发送 |
| `0x212` | 枪管→上位机 | 上电/初始化完成 | 0 | 初始化完成后发送一次 |
| `0x220` | 上位机→枪管 | 请求传感器校正 | 0 | 收到后在主循环执行 |
| `0x221` | 枪管→上位机 | 传感器校正 ACK | 8 | 校正完成或失败后发送 |
| `0x230` | 枪管→上位机 | 有效射击事件 | 8 | 每次有效射击发送 |
| `0x231` | 上位机→枪管 | 射击状态查询 | 0 或 8 | 收到后回复 `0x232` |
| `0x232` | 枪管→上位机 | 射击状态回复 | 8 | 回复 `0x231` |
| `0x233` | 上位机→枪管 | LED/队伍/热量控制 | 8 | 有效命令执行 |
| `0x234` | 枪管→上位机 | 控制命令 ACK | 8 | 原样回显 `0x233` 数据 |


## 2. 故障与启动报文

### `0x210` 强故障复位后上报

`DLC=1`，`Byte0` 为组合掩码：`bit0` HardFault，`bit1` 看门狗复位，`bit2` CAN Bus-Off，`bit3` 其他异常复位，`bit7` 未定义强故障。CAN Bus-Off 只在被明确判定为需要复位的场景下进入强故障复位流程；未接 CAN 节点时，枪管继续独立运行，不因无 ACK 而复位。

强故障发生时不发送 CAN 故障帧；先保存标志并复位，重新初始化成功后按 `0x210`、`0x212` 顺序发送。HardFault 现场的 PC/LR/xPSR 仅保存在内部调试记录中。

### `0x211` 弱故障状态

`DLC=1`，`Byte0` 为组合掩码：`bit0` 前端传感器，`bit1` 后端传感器，`bit2` 发射检测/测速，`bit3` 关键任务，`bit4` 事件队列，`bit7` 未定义弱故障。

同类异常连续确认 3 次后置位；故障持续时约每 100 ms 重发。故障恢复后发送 `Byte0=0` 清除状态。弱故障期间顶部状态灯红、蓝、绿快速交替。

### `0x212` 启动完成

`DLC=0`。所有必要初始化和启动校正完成后发送一次。正常启动只发送 `0x212`；强故障复位后的启动顺序为 `0x210 → 0x212`。

## 3. 设备层：传感器校正

### 请求 `0x220`

仅接受标准数据帧、`DLC=0`。枪管读取前、后 VCNL4040 各 20 次 `PS_DATA` 并取平均作为 baseline，然后设置：

```text
THDL = baseline - 20（不足 20 时钳位为 0）
THDH = baseline
中断模式 = AWAY
```

AWAY 条件为 `PS_DATA < THDL`。校正过程在主循环执行，不在 CAN 接收中断中阻塞 I2C。

### ACK `0x221`

`DLC=8`，四个 `uint16` 小端字段：`Byte0~1` 前端校正前 baseline，`Byte2~3` 前端校正后 baseline，`Byte4~5` 后端校正前 baseline，`Byte6~7` 后端校正后 baseline。校正失败时对应“校正后 baseline”填 `0xFFFF`。

## 4. 应用层：射击状态

### 有效射击事件 `0x230`

后端传感器先触发、前端传感器后触发，且速度在 `0~50 m/s` 内时确认有效射击：`Byte0~3` 累计有效射击次数，`Byte4~5` 本次速度（0.01 m/s），`Byte6` `barrel_mask` 低 5 位，`Byte7` 本次射击后的热量（0~45）。有效射击判定后立即启动本地顶部状态灯；CAN 未连接或暂时发送失败不影响本地计数、热量和灯效，`0x230` 事件会留在队列中等待发送。

TIM16 为 20 kHz，时间分辨率 50 μs；速度计算为 `v = 1000 / delta_ticks`。

### 查询 `0x231` 与回复 `0x232`

`0x231` 仅接受标准数据帧且 DLC 为 0 或 8；DLC=8 时数据应填 0。`0x232` 的 Byte0~3 为累计次数，Byte4~5 为最近速度（0.01 m/s），Byte6 为 `barrel_mask`，Byte7 为当前热量。

### 热量

上电/复位后热量为 0；每次有效射击加 1，最大钳位为 45，但达到 45 后仍继续计数和上报；每 500 ms 自动减 1，最低为 0。枪管只计算和上报热量，不执行裁判系统的 3 秒射击处罚。

## 5. LED、队伍和热量控制

### 命令 `0x233`

必须为标准数据帧、`DLC=8`：Byte0 为命令，Byte1 为参数，Byte2~7 保留并填 0。

| Byte0 | 功能 | Byte1 |
|---:|---|---:|
| `0x00` | 恢复自动模式 | 无 |
| `0x01` | 设置红队 | 无 |
| `0x02` | 设置蓝队 | 无 |
| `0x03` | 设置当前热量 | `0~45` |
| `0x10` | 全绿测试 | 无 |
| `0x11` | 全红测试 | 无 |
| `0x12` | 全蓝测试 | 无 |
| `0x1F` | 全灭 | 无 |

`0x03` 越界、未知命令或格式错误时忽略且不 ACK。有效命令执行后，以 `0x234` 原样回显 8 字节数据。正常显示时后段 8 灯按 `0~45` 热量范围显示队伍色（即热量百分比）；顶部状态灯空闲为低亮黄，热量达到 45 时队伍色常亮约 3 秒。

## 6. 非 CAN 调试接口

固件保留 USART2 的 `F`、`R`、`D` 采集命令供调试：分别采集前端 5 秒、后端 5 秒、双通道 200 Hz 采集 10 秒。它们不属于比赛 CAN 协议。
