# 枪管 CAN 通信协议

版本：v3.2（设备层与应用层分离）  
适用工程：`SHOOT_cmzy_REV081`

## 1. 总线定义

- 经典 CAN，标准 11 位 ID，数据帧 `CAN_RTR_DATA`
- 波特率：500 kbps
- 多字节整数：小端序；不使用扩展帧
- CAN ID 数值越小，仲裁优先级越高

```text
0x20x：调试层
0x21x：故障层
0x22x：设备层
0x23x：应用层
```

## 2. ID 分配

| ID | 方向 | 报文 | DLC | 触发 |
|---:|---|---|---:|---|
| `0x200` | 保留 | 调试心跳 | 8 | 当前固件不发送 |
| `0x210` | 枪管 → 上位机 | 强故障复位后上报 | 1 | 强故障复位并初始化完成后 |
| `0x211` | 枪管 → 上位机 | 弱故障 | 1 | 故障首次发生及持续期间 |
| `0x212` | 枪管 → 上位机 | 上电/初始化完成 | 0 | 每次初始化完成 |
| `0x220` | 上位机 → 枪管 | 请求传感器校正 | 0 | 上位机请求 |
| `0x221` | 枪管 → 上位机 | 传感器校正 ACK | 1 | 校正完成后 |
| `0x230` | 枪管 → 上位机 | 有效射击事件 | 8 | 每次有效射击确认后 |
| `0x231` | 上位机 → 枪管 | 射击状态查询 | 0 或 8 | 上位机请求 |
| `0x232` | 枪管 → 上位机 | 射击状态回复 | 8 | 收到 `0x231` 后 |
| `0x233` | 上位机 → 枪管 | LED/队伍/热量控制 | 8 | 控制命令 |
| `0x234` | 枪管 → 上位机 | LED/队伍/热量控制 ACK | 8 | 收到并执行 `0x233` 后 |

旧的 `0x200~0x204` 功能分配、`0x300`、`0x400` 均废弃。

## 3. 调试与可靠性帧

### 调试心跳：`0x200`

当前固件主循环不发送；保留格式如下：

```text
DLC=8
Byte0=0xA5，Byte1=0x01
Byte2~5=运行秒数 uint32，小端
Byte6=当前热量
Byte7=barrel_mask
```

### 强故障复位后上报：`0x210`

```text
DLC=1，Byte0=强故障掩码
bit0=HardFault，bit1=看门狗复位，bit2=CAN Bus-Off
bit3=其他异常复位，bit7=通用/未定义强故障
```

强故障发生时不尝试发送；MCU 复位并完成初始化后发送。

### 弱故障：`0x211`

```text
DLC=1，Byte0=弱故障掩码
bit0=前端传感器，bit1=后端传感器，bit2=测速/发射检测
bit3=关键任务超时，bit4=事件队列溢出，bit7=通用/未定义弱故障
```

连续确认 3 次后进入弱故障。首次确认立即发送，持续时每 100 ms 重发；恢复后不发送恢复帧。弱故障期间 RGB 红、蓝、绿快速交替。

### 上电/初始化完成：`0x212`

`DLC=0`，无数据。正常启动发送 `0x212`；强故障重启发送顺序为 `0x210 → 0x212`。

## 4. 设备层：传感器校正

### 请求校正：`0x220`

```text
DLC=0，DATA 为空
```

枪管收到有效请求后，读取前、后两颗传感器各 20 次 `PS_DATA`，取平均值作为新 baseline，设置：

```text
THDL = baseline - 45
THDH = baseline
```

VCNL4040 使用 AWAY 中断模式，`PS_DATA < THDL` 时判定遮挡。CAN 接收中断只记录请求；I2C 校正在主循环执行，避免中断阻塞。非标准帧或 DLC 不为 0 的 `0x220` 忽略，不 ACK。

### 校正 ACK：`0x221`

```text
DLC=1
Byte0=0x00：校正成功
Byte0=0x01：校正失败（至少一次 I2C 读取失败）
```

## 5. 应用层：射击状态

### 有效射击事件：`0x230`

前后传感器依次触发且速度有效时，枪管主动发送：

```text
DLC=8
Byte0~3：累计有效射击次数 uint32，小端
Byte4~5：本次速度，单位 0.01 m/s，uint16，小端
Byte6：barrel_mask，低 5 位有效
Byte7：事件标志，固定 0x01
```

### 射击状态查询：`0x231`

上位机发送标准数据帧，DLC 只能为 0 或 8；DLC=8 时 Byte0~7 填 0。其他帧忽略，不回复。

### 射击状态回复：`0x232`

```text
DLC=8
Byte0~3：累计有效射击次数 uint32，小端
Byte4~5：最近速度，单位 0.01 m/s，uint16，小端
Byte6：barrel_mask，低 5 位有效
Byte7：当前热量，0~255
```

## 6. 应用层：LED/队伍/热量控制

### 命令：`0x233`

```text
DLC=8
Byte0：命令
Byte1：参数
Byte2~7：保留，填 0
```

| Byte0 | 功能 | Byte1 |
|---:|---|---:|
| `0x00` | 恢复自动模式 | 无 |
| `0x01` | 设置红队 | 无 |
| `0x02` | 设置蓝队 | 无 |
| `0x03` | 设置热量 | `0~255` |
| `0x10` | 全绿测试 | 无 |
| `0x11` | 全红测试 | 无 |
| `0x12` | 全蓝测试 | 无 |
| `0x1F` | 全灭 | 无 |

只有标准数据帧、DLC=8、且 Byte0 为已定义命令时才执行。未知命令或格式错误的帧忽略，不 ACK。

### 命令 ACK：`0x234`

收到并执行有效 `0x233` 后立即发送。DLC 和 Byte0~7 与接收命令完全相同。
